## The one rule that matters today

There are two ways to use Claude today, and we want both:

| Built with Claude | Runs on Claude |
|---|---|
| Claude Code, Cowork, Claude Design write your app. Fast prototyping. Every team will do this. | Every time a citizen or an officer uses your solution, **Claude does the work**: understands, translates, reasons over rules, fills in, routes. Through the API, as an agent, or behind an MCP server. |

**The test:** switch the AI off. If what's left is a static page, a nicer form or a dashboard, the solution doesn't run on AI yet.

This is scored: **AI at work** counts double (see [RULES.md](RULES.md)), and your README must explain *where Claude works when someone uses it*.

## Getting set up (10 minutes)

1. **A GitHub account** for every team member. One public repo per team.
2. **Your Claude plan** (Pro or Max) to *build* with Claude Code, Cowork or claude.ai. Aim for at least one Max plan per team.
3. **$100 in Claude API credits each**, from Anthropic, to *run* your solution:
   1. Sign in at [console.anthropic.com](https://console.anthropic.com) and create your organization.
   2. Copy your **Org ID** from the console settings. Not your Claude.ai ID: it will be rejected.
   3. Scan the QR code shown in the room (also at the registration desk) and submit your Org ID **once**. One claim per person; multiple profiles get blocked automatically.
   4. Create an API key in the console and put it in your app's environment (`ANTHROPIC_API_KEY`), never in the repo.

   Credits work with the API only, not with claude.ai. They run out quickly if you use them to build with Claude Code: keep them for your solution.
4. Clone this repo and open it with Claude. It is written to be read by Claude as context.
